# BCD Digital Clock

A digital clock that shows hours, minutes and seconds in BCD, built as a university term project. The repo contains the complete hardware design, a simulation, and the written report.

## Contents

| Folder | What is inside |
|---|---|
| `BCD CLOCK/` | Altium Designer project: schematics (`SCH/`: clock-set switches, hour display, seconds and minutes display), two PCB revisions (`PCB/PCB_v1.0`, `PCB_v2.0`), a custom schematic and footprint library, BOM and output job |
| `BCD_Protius_01/` | Proteus simulation projects for the first and updated versions |
| `Doc/` | Project requirements and the report on the BCD digital clock (PDF) |

## How to open

- Altium: open `BCD CLOCK/BCD CLOCK.PrjPcb`. The library is in `BCD CLOCK/Library/`.
- Proteus: open `BCD_Protius_01/UPdated_BCD CLOCK Project.pdsprj`.
- Read `Doc/Report_on_the_BCD_Digital_Clock.pdf` for the design explanation.
